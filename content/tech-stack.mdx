# 기술 스택

프로젝트 전반에서 사용하는 기술을 영역별로 정리합니다. 각 영역의 상세
맥락은 [아키텍처](/architecture) 문서를 함께 참고하세요.

## 백엔드

| 분류 | 기술 |
| --- | --- |
| Runtime | Java 17 (LTS) |
| Framework | Spring Boot 3.2.4 |
| Build Tool | Gradle 8.5 |
| Database | PostgreSQL 15 |
| API 문서화 | Springdoc OpenAPI 3.0 |
| 인증 | JWT, OAuth2 |
| 컨테이너 | Docker, Docker Compose |

## 프론트엔드

| 분류 | 기술 |
| --- | --- |
| Framework | Next.js (App Router) |
| UI Library | React |
| 폰트 최적화 | next/font (Geist) |
| 스타일링 | vanilla-extract (CSS-in-TS) |
| 아키텍처 패턴 | FSD 유사 구조 (entities / features / shared / views / widgets) |
| 디자인 협업 | Figma |

## 인프라 & 협업 도구

| 분류 | 기술 |
| --- | --- |
| CI | GitHub Actions (PR 빌드 검증) |
| CD | GitHub Actions → Docker Hub 이미지 배포 |
| 문서/랜딩 배포 | Vercel |
