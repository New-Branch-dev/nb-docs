## 팀 구성

New Branch는 기획자·백엔드 개발자가 서비스 개발을 진행 중이며, 베타 →
정식 출시를 함께할 UX/UI 디자이너와 프론트엔드 개발자를 모집해 합류시키는
구조로 팀을 꾸리고 있습니다.

| 역할 | 이름 | 담당 영역 | 참여 형태 |
| --- | --- | --- | --- |
| 기획 | _추후 작성_ | 서비스 기획 | _추후 작성_ |
| 백엔드 개발 | _추후 작성_ | API 서버 / DB / 인프라 | _추후 작성_ |
| 프론트엔드 개발 | _추후 작성_ | 웹 클라이언트 구현 | 원격 협업, 주 10시간 내외 |
| UX/UI 디자인 | _추후 작성_ | 서비스 전체 UX/UI, 디자인 시스템 | 원격 협업, 주 10시간 내외 |

## 역할별 주요 업무 (모집 공고 기준)

### UX/UI 디자이너

- 서비스 전체 사용자 흐름(User Flow) 설계
- 웹 및 앱 화면 구조 설계 (Information Architecture)
- Figma 기반 와이어프레임 제작
- UI 디자인 제작 (노트, 마인드맵, 학습 플랜, 투표, 관리자 페이지 등)
- 디자인 시스템 구축 (컬러, 타이포그래피, 컴포넌트 등)
- 개발자와 협업하여 디자인 → 개발 전달
- 사용자 경험 개선 및 인터페이스 고도화

### 프론트엔드 개발자

- UI 구현: 디자이너의 설계안을 바탕으로 실제 서비스 화면(React) 개발
- API 연동: 백엔드 API를 활용해 데이터를 화면에 연결
- 기능 구현: 로그인 UI 연동, 자료 업로드 및 투표 시스템 인터페이스 구축
- 최적화: 서비스 소개 랜딩 페이지 제작 및 프런트엔드 안정화

## 협업 방식

- 원격 협업 가능, 주 1회 내외 온라인 미팅
- 필요 시 수도권 오프라인 미팅
- 협업 툴: Figma / React, Notion, Discord, GitHub
