# New Branch (뉴브랜치)

> 학습자가 스스로 학습 목표를 설정하고, 자료를 업로드·정리하며, 탐구 주제
> 투표·마인드맵·기록·성찰까지 학습의 전 과정을 하나의 흐름으로 연결하는
> **교육용 AI 학습 플랫폼**입니다.

이 저장소는 New Branch 프로젝트의 기술적인 결정과 구조를 정리한 기술문서
모음입니다. 신규 합류자가 프로젝트를 빠르게 파악하고, 팀원 간 아키텍처·기술
스택·디자인 히스토리를 공유하기 위한 용도로 사용합니다.

## 서비스 개요

New Branch는 단순한 학습 관리 도구가 아니라, 학생이 스스로 학습을 설계하고
탐구하는 환경을 만드는 것을 목표로 합니다.

- 학습자가 직접 **학습 목표를 설정**하고 진행 상황을 관리
- 자료를 업로드하고 **정리(요약/보관)**
- 탐구 주제에 대한 **투표**로 학습 방향을 함께 결정
- **마인드맵**을 통한 생각 정리
- 학습 과정에 대한 **기록과 성찰**

현재는 웹 서비스를 중심으로 개발이 진행되고 있으며, 서비스가 안정화되면
앱 서비스로 확장할 계획입니다.

## 프로젝트 현황

- 기획자·백엔드 개발자가 참여해 실제 서비스 개발이 진행 중인 단계입니다.
- 베타 → 정식 출시를 목표로 UX/UI 디자이너, 프론트엔드 개발자와 함께
  기능을 안정화·고도화하고 있습니다.
- 백엔드는 초기 프로젝트 설정(도메인 구조, CI/CD, 개발 문서)을 완료하고
  도메인별 기능 구현 단계로 진입했습니다.
